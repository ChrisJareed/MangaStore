MANGASTORE WEB - INICIO RAPIDO

VERSION ACTUAL:
Interfaz renovada con menu, resumen de la tienda, formularios y comprobantes.
No se muestran consultas MongoDB, codigo ni respuestas JSON en la pagina.
La conexion y la base de datos no cambian.

SI YA TENIAS LA VERSION ANTERIOR:
Deten el servidor con Ctrl + C.
Reemplaza solo public/index.html, public/styles.css y public/app.js.
Ejecuta npm.cmd start y recarga la pagina con Ctrl + F5.
No repitas preparar-demo. No reemplaces tu .env.
Opcional: reemplaza LEEME.md, ABRIR_EN_WINDOWS.txt y test/interfaz.test.js
para conservar las instrucciones y pruebas de esta version.

PRIMERA INSTALACION:
1. Extrae toda la carpeta MangaStore_Web. No abras index.html con doble clic.
2. Comprueba que tienes Node.js 24 o superior y tu servidor MongoDB iniciado.
3. Abre una terminal donde esta package.json.
4. Primera vez:
   npm.cmd install
   npm.cmd run preparar-demo
5. Para abrir la web:
   npm.cmd start
6. En el navegador:
   http://localhost:3000
7. Deja la terminal abierta mientras usas la web.

La base se llama mangastore_ep3_web_demo.
No se utiliza ni se modifica tu mangastore_ep3 original.
Si la base ya esta preparada, omite preparar-demo.
Para detener el servidor: Ctrl + C en la terminal.

Lee LEEME.md para ver el recorrido de demostracion y las explicaciones.
